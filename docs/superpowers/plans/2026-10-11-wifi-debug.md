# Wi-Fi Debug Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The PC reads the board's log lines (`GET /log`) and a screenshot (`GET /shot`) over Wi-Fi. The user sets the Wi-Fi network on the touchscreen.

**Architecture:** A new `wifi_debug` module runs the Wi-Fi station, mDNS (`macropad.local`) and a log hook that copies every log line into a 4 KB ring buffer. A small HTTP server (`wifi_http`) streams the ring on `/log` (in its own task, so `/shot` still answers) and sends an LVGL snapshot as a BMP on `/shot`. A "Wi-Fi" entry in Settings turns it on and sets the network. Wi-Fi is off by default and the switch is saved in NVS.

**Tech Stack:** ESP-IDF 5.2.1 (PlatformIO `espressif32@6.6.0`), `esp_wifi`, `esp_http_server`, managed component `espressif/mdns`, LVGL 8.4.0 (`lv_snapshot`, `lv_keyboard`), C11 host tests.

**Spec:** `docs/superpowers/specs/2026-10-11-wifi-debug-design.md`

## Global Constraints

- Wi-Fi is off by default; the switch is saved in NVS (`wifi_en`). Nothing about the network goes in git.
- Credentials are typed on the touchscreen and saved in NVS (`wifi_ssid`, `wifi_pass`). They are never printed to the log.
- No authentication on `/log` and `/shot`.
- mDNS name: `macropad.local`. The Wi-Fi page also shows the IP.
- One HTTP server, port 80. `/log` allows one client at a time (a second gets HTTP 503).
- Log ring: 4 KB. The log hook never blocks and never allocates.
- Snapshot buffer: allocated for one request only, in PSRAM. If it fails, answer HTTP 503.
- `LV_COLOR_16_SWAP` is 1 in `src/lv_conf.h`: snapshot pixels are RGB565 with the two bytes swapped.
- Never use partial refresh on this display (see project memory `macropad-display-limits`). This plan does not touch the display path.
- The display is 480 x 320 in LVGL (`SCREEN_W 480`, tileview height 320, `DOTS_Y 298`).
- Do not change any existing page except to add the Settings sidebar entry.
- Work on branch `CodyECSL/wifi-debugging`, never on `main`. Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Out of scope: OTA flashing, touch injection, authentication, TLS, hidden SSIDs, more than one log client.

## Tools and commands used in this plan

- Host tests: `tests/host/run.sh` (no board needed).
- Build: `~/.venvs/platformio/bin/pio run` (PlatformIO is not on PATH).
- Flash (the user must hold the on-screen "USB connected" label for 3 s first; the board then shows as `/dev/ttyACM0`): `~/.venvs/platformio/bin/pio run -t upload --upload-port /dev/ttyACM0`. After the flash the board comes back as `303a:4004`. Do not ask the user to press BOOT+RST.
- Give the user full commands in plain text in the chat, not only inside a question dialog.

Create `src/log_ring.h`:

```c
#pragma once

#include <stddef.h>
#include <stdint.h>

/* A fixed-size ring of log text. Readers keep their own absolute position, so the writer never waits for them.
 * Not thread-safe: the caller serializes write and read. */
typedef struct {
    char *buf;
    size_t cap;
    uint64_t total; /* bytes ever written; byte k is at buf[k % cap] */
} log_ring_t;

void log_ring_init(log_ring_t *r, char *storage, size_t cap);
void log_ring_write(log_ring_t *r, const char *data, size_t len);

/** Copy up to `max` bytes from absolute position *pos and advance *pos. If *pos is older than the oldest kept
 * byte, *pos jumps to the oldest byte and *skipped (may be NULL) is the number of bytes lost. Returns bytes copied. */
size_t log_ring_read(const log_ring_t *r, uint64_t *pos, char *out, size_t max, size_t *skipped);
```

Create `src/log_ring.c`:

```c
#include "log_ring.h"

#include <string.h>

void log_ring_init(log_ring_t *r, char *storage, size_t cap)
{
    r->buf = storage;
    r->cap = cap;
    r->total = 0;
}

void log_ring_write(log_ring_t *r, const char *data, size_t len)
{
    if (len > r->cap) {
        /* only the last `cap` bytes can stay; count the others as written and lost */
        r->total += len - r->cap;
        data += len - r->cap;
        len = r->cap;
    }
    size_t off = (size_t)(r->total % r->cap);
    size_t first = r->cap - off;
    if (first > len) {
        first = len;
    }
    memcpy(r->buf + off, data, first);
    memcpy(r->buf, data + first, len - first);
    r->total += len;
}

size_t log_ring_read(const log_ring_t *r, uint64_t *pos, char *out, size_t max, size_t *skipped)
{
    size_t lost = 0;
    uint64_t oldest = r->total > r->cap ? r->total - r->cap : 0;
    if (*pos < oldest) {
        lost = (size_t)(oldest - *pos);
        *pos = oldest;
    }
    if (skipped) {
        *skipped = lost;
    }
    if (*pos >= r->total) {
        *pos = r->total; /* also repairs a position from before a reset */
        return 0;
    }
    uint64_t avail = r->total - *pos;
    size_t n = avail < max ? (size_t)avail : max;
    size_t off = (size_t)(*pos % r->cap);
    size_t first = r->cap - off;
    if (first > n) {
        first = n;
    }
    memcpy(out, r->buf + off, first);
    memcpy(out + first, r->buf, n - first);
    *pos += n;
    return n;
}
```

```c
#pragma once

#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

#define BMP_HEADER_SIZE 54

/** Bytes of one 24 bit BMP row: width * 3, padded up to a multiple of 4. */
size_t bmp_row_bytes(int width);

/** File header + DIB header for a 24 bit, top-down image (negative height), no compression. */
void bmp_header(uint8_t out[BMP_HEADER_SIZE], int width, int height);

/** Convert `width` RGB565 pixels (2 bytes each) to one BMP row (B, G, R, zero padding).
 * `byte_swapped`: each pixel is stored high byte first (LVGL with LV_COLOR_16_SWAP 1). */
void bmp_row_from_rgb565(const uint8_t *src, int width, bool byte_swapped, uint8_t *dst);
```

Create `src/bmp.c`:

```c
#include "bmp.h"

#include <string.h>

static void put16(uint8_t *p, uint16_t v)
{
    p[0] = (uint8_t)v;
    p[1] = (uint8_t)(v >> 8);
}

static void put32(uint8_t *p, uint32_t v)
{
    put16(p, (uint16_t)v);
    put16(p + 2, (uint16_t)(v >> 16));
}

size_t bmp_row_bytes(int width)
{
    return ((size_t)width * 3 + 3) & ~(size_t)3;
}

void bmp_header(uint8_t out[BMP_HEADER_SIZE], int width, int height)
{
    uint32_t image = (uint32_t)(bmp_row_bytes(width) * (size_t)height);
    memset(out, 0, BMP_HEADER_SIZE);
    out[0] = 'B';
    out[1] = 'M';
    put32(out + 2, BMP_HEADER_SIZE + image);
    put32(out + 10, BMP_HEADER_SIZE);
    put32(out + 14, 40);
    put32(out + 18, (uint32_t)width);
    put32(out + 22, (uint32_t)(-height));
    put16(out + 26, 1);
    put16(out + 28, 24);
    put32(out + 34, image);
    put32(out + 38, 2835); /* 72 dpi */
    put32(out + 42, 2835);
}

void bmp_row_from_rgb565(const uint8_t *src, int width, bool byte_swapped, uint8_t *dst)
{
    for (int x = 0; x < width; x++) {
        uint16_t p = byte_swapped ? (uint16_t)((src[2 * x] << 8) | src[2 * x + 1])
                                  : (uint16_t)(src[2 * x] | (src[2 * x + 1] << 8));
        unsigned r = p >> 11;
        unsigned g = (p >> 5) & 0x3F;
        unsigned b = p & 0x1F;
        dst[3 * x] = (uint8_t)((b << 3) | (b >> 2));
        dst[3 * x + 1] = (uint8_t)((g << 2) | (g >> 4));
        dst[3 * x + 2] = (uint8_t)((r << 3) | (r >> 2));
    }
    size_t used = (size_t)width * 3;
    memset(dst + used, 0, bmp_row_bytes(width) - used);
}
```

```c
static int hook_vprintf(const char *fmt, va_list args)
{
    char line[256];
    va_list copy;
    va_copy(copy, args);
    int n = vsnprintf(line, sizeof(line), fmt, copy);
    va_end(copy);
    if (n > 0) {
        size_t len = (size_t)n < sizeof(line) ? (size_t)n : sizeof(line) - 1;
        portENTER_CRITICAL(&s_ring_lock);
        log_ring_write(&s_ring, line, len);
        portEXIT_CRITICAL(&s_ring_lock);
    }
    return s_old_vprintf ? s_old_vprintf(fmt, args) : vprintf(fmt, args);
}

static void retry_cb(void *arg)
{
    (void)arg;

static void schedule_retry(void)
{
    uint64_t delay_ms = 1000u << (s_retry < 5 ? s_retry : 5); /* 1 s .. 32 s */
    s_retry++;
    esp_timer_stop(s_retry_timer);
    esp_timer_start_once(s_retry_timer, delay_ms * 1000u);
}

static void scan_done(void)
{
    uint16_t n = SCAN_MAX;
    wifi_ap_record_t recs[SCAN_MAX];
    esp_wifi_scan_get_ap_records(&n, recs);
    int count = 0;
    for (int i = 0; i < n; i++) {
        bool dup = false;
        for (int j = 0; j < count; j++) {
            dup |= strcmp(s_scan[j].ssid, (const char *)recs[i].ssid) == 0;
        }
        if (dup || recs[i].ssid[0] == '\0') {
            continue; /* the list is sorted by signal, so the first entry of a name is the strongest */
        }
        snprintf(s_scan[count].ssid, sizeof(s_scan[count].ssid), "%s", (const char *)recs[i].ssid);
        s_scan[count].rssi = recs[i].rssi;
        count++;
    }
    s_scan_count = count;
    s_scan_running = false;
}

static void on_event(void *arg, esp_event_base_t base, int32_t id, void *data)
{
    (void)arg;
    if (base == WIFI_EVENT) {
        switch (id) {
        case WIFI_EVENT_STA_START:
            if (has_network()) {
                set_status(WIFI_DEBUG_CONNECTING, NULL, NULL);
                esp_wifi_connect();
            }
            break;
        case WIFI_EVENT_STA_DISCONNECTED: {
            wifi_event_sta_disconnected_t *d = data;
            char why[24];
            reason_text(d->reason, why, sizeof(why));
            ESP_LOGW(TAG, "disconnected: %s (%d)", why, d->reason);
            if (s_running && has_network()) {
                set_status(WIFI_DEBUG_FAILED, NULL, why);
                schedule_retry();
            }
            break;
        }
        case WIFI_EVENT_SCAN_DONE:
            scan_done();
            break;
        default:
            break;
        }
    } else if (base == IP_EVENT && id == IP_EVENT_STA_GOT_IP) {
        ip_event_got_ip_t *e = data;
        char ip[16];
        snprintf(ip, sizeof(ip), IPSTR, IP2STR(&e->ip_info.ip));
        s_retry = 0;
        set_status(WIFI_DEBUG_CONNECTED, ip, NULL);
        ESP_LOGI(TAG, "connected, ip %s, host %s.local", ip, HOSTNAME);
        ESP_LOGI(TAG, "free internal %u, min internal %u, free PSRAM %u",
                 (unsigned)heap_caps_get_free_size(MALLOC_CAP_INTERNAL),
                 (unsigned)heap_caps_get_minimum_free_size(MALLOC_CAP_INTERNAL),
                 (unsigned)heap_caps_get_free_size(MALLOC_CAP_SPIRAM));
    }
}

static void start(void)
{
    if (s_running) {
        return;
    }
    s_ring_store[0] = '\0';
    log_ring_init(&s_ring, s_ring_store, sizeof(s_ring_store));
    s_old_vprintf = esp_log_set_vprintf(hook_vprintf);

    esp_netif_init();
    esp_event_loop_create_default(); /* returns ESP_ERR_INVALID_STATE if it exists; fine */
    s_netif = esp_netif_create_default_wifi_sta();
    wifi_init_config_t init = WIFI_INIT_CONFIG_DEFAULT();
    esp_wifi_init(&init);
    esp_wifi_set_storage(WIFI_STORAGE_RAM); /* credentials live in our NVS keys only */
    esp_event_handler_register(WIFI_EVENT, ESP_EVENT_ANY_ID, on_event, NULL);
    esp_event_handler_register(IP_EVENT, IP_EVENT_STA_GOT_IP, on_event, NULL);
    esp_wifi_set_mode(WIFI_MODE_STA);

    if (!s_retry_timer) {
        const esp_timer_create_args_t args = {.callback = retry_cb, .name = "wifi_retry"};
        esp_timer_create(&args, &s_retry_timer);
    }
    s_retry = 0;
    s_scan_running = false;
    s_scan_count = 0;
    s_running = true;
    set_status(WIFI_DEBUG_OFF, NULL, has_network() ? NULL : "no network set");
    if (has_network()) {
        apply_config();
    }
    esp_wifi_start();

    mdns_init();
    mdns_hostname_set(HOSTNAME);
    mdns_instance_name_set("Macropad");
    wifi_http_start();
    ESP_LOGI(TAG, "started");
}

static void stop(void)
{
    if (!s_running) {
        return;
    }
    s_running = false;
    wifi_http_stop();
    esp_timer_stop(s_retry_timer);
    mdns_free();
    esp_event_handler_unregister(WIFI_EVENT, ESP_EVENT_ANY_ID, on_event);
    esp_event_handler_unregister(IP_EVENT, IP_EVENT_STA_GOT_IP, on_event);
    esp_wifi_stop();
    esp_wifi_deinit();
    esp_netif_destroy_default_wifi(s_netif);
    s_netif = NULL;
    esp_log_set_vprintf(s_old_vprintf ? s_old_vprintf : vprintf);
    set_status(WIFI_DEBUG_OFF, NULL, NULL);
    ESP_LOGI(TAG, "stopped, free internal %u", (unsigned)heap_caps_get_free_size(MALLOC_CAP_INTERNAL));
}
```

**Files:**

**Interfaces:**

- Produces: `GET /log` on port 80 (text, never ends until the client leaves). `wifi_http_start/stop` keep the signatures from Task 4.

```c
#include "wifi_http.h"

#include <errno.h>
#include <stdio.h>
#include <sys/socket.h>

#include "esp_http_server.h"
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "mdns.h"

#include "wifi_debug.h"

static const char *TAG = "wifi_http";

static httpd_handle_t s_server;
static volatile bool s_log_busy;

static void send_status(httpd_req_t *req, const char *status, const char *text)
{
    httpd_resp_set_status(req, status);
    httpd_resp_sendstr(req, text);
}

/* True when the peer has closed the connection. Looks at the socket without taking data. */
static bool client_gone(httpd_req_t *req)
{
    char c;
    int r = recv(httpd_req_to_sockfd(req), &c, 1, MSG_PEEK | MSG_DONTWAIT);
    return r == 0 || (r < 0 && errno != EAGAIN && errno != EWOULDBLOCK);
}

/* One task per log client. The httpd task must stay free so /shot still answers. */
static void log_task(void *arg)
{
    httpd_req_t *req = arg;
    char chunk[256];
    uint64_t pos = 0; /* from the oldest text still in the ring */
    esp_err_t err = ESP_OK;
    httpd_resp_set_type(req, "text/plain");
    httpd_resp_set_hdr(req, "Cache-Control", "no-store");
    while (err == ESP_OK) {
        size_t skipped = 0;
        size_t n = wifi_debug_log_read(&pos, chunk, sizeof(chunk), &skipped);
        if (skipped) {
            char note[48];
            int len = snprintf(note, sizeof(note), "[%u bytes of log lost]\n", (unsigned)skipped);
            err = httpd_resp_send_chunk(req, note, len);
        }
        if (n > 0 && err == ESP_OK) {
            err = httpd_resp_send_chunk(req, chunk, (ssize_t)n);
        } else if (n == 0) {
            if (client_gone(req)) {
                break;
            }
            vTaskDelay(pdMS_TO_TICKS(100));
        }
    }
    httpd_resp_send_chunk(req, NULL, 0);
    httpd_req_async_handler_complete(req);
    s_log_busy = false;
    vTaskDelete(NULL);
}

static esp_err_t log_get(httpd_req_t *req)
{
    if (s_log_busy) {
        send_status(req, "503 Service Unavailable", "one log client at a time\n");
        return ESP_OK;
    }
    httpd_req_t *async;
    if (httpd_req_async_handler_begin(req, &async) != ESP_OK) {
        send_status(req, HTTPD_500, "no async handler\n");
        return ESP_OK;
    }
    s_log_busy = true;
    if (xTaskCreate(log_task, "log_http", 4096, async, 5, NULL) != pdPASS) {
        s_log_busy = false;
        send_status(async, HTTPD_500, "no task\n");
        httpd_req_async_handler_complete(async);
    }
    return ESP_OK;
}

void wifi_http_start(void)
{
    if (s_server) {
        return;
    }
    httpd_config_t cfg = HTTPD_DEFAULT_CONFIG();
    cfg.max_open_sockets = 4;
    cfg.lru_purge_enable = true;
    cfg.stack_size = 6144;
    if (httpd_start(&s_server, &cfg) != ESP_OK) {
        ESP_LOGE(TAG, "httpd_start failed");
        s_server = NULL;
        return;
    }
    static const httpd_uri_t log_uri = {.uri = "/log", .method = HTTP_GET, .handler = log_get};
    httpd_register_uri_handler(s_server, &log_uri);
    mdns_service_add(NULL, "_http", "_tcp", 80, NULL, 0);
    ESP_LOGI(TAG, "http server started");
}

void wifi_http_stop(void)
{
    if (!s_server) {
        return;
    }
    /* httpd_stop closes the sockets; a running log_task sees the error on its next send and ends itself. */
    httpd_stop(s_server);
    s_server = NULL;
}
```

Notes: in `log_get` the first `send_status` call uses the original request, which is fine because no async copy exists yet. In the failure branch after `httpd_req_async_handler_begin` the reply goes through `async`.

`wifi_debug.c` calls `wifi_http_stop()` before `mdns_free()` (Task 4), so `mdns_service_add` is not left dangling. `wifi_http_start()` is called after `mdns_init()` (Task 4), so the service add works.

```c
#define SHOT_ROWS_PER_CHUNK 8

static esp_err_t shot_get(httpd_req_t *req)
{
    if (!bsp_display_lock(2000)) {
        send_status(req, "503 Service Unavailable", "display busy\n");
        return ESP_OK;
    }
    lv_img_dsc_t *snap = lv_snapshot_take(lv_scr_act(), LV_IMG_CF_TRUE_COLOR);
    bsp_display_unlock();
    if (!snap) {
        send_status(req, "503 Service Unavailable", "no memory for the snapshot\n");
        return ESP_OK;
    }

    int w = snap->header.w;
    int h = snap->header.h;
    size_t row_bytes = bmp_row_bytes(w);
    uint8_t *out = malloc(row_bytes * SHOT_ROWS_PER_CHUNK);
    esp_err_t err = out ? ESP_OK : ESP_ERR_NO_MEM;
    if (out) {
        uint8_t head[BMP_HEADER_SIZE];
        bmp_header(head, w, h);
        httpd_resp_set_type(req, "image/bmp");
        httpd_resp_set_hdr(req, "Cache-Control", "no-store");
        err = httpd_resp_send_chunk(req, (const char *)head, BMP_HEADER_SIZE);
        for (int y = 0; y < h && err == ESP_OK; y += SHOT_ROWS_PER_CHUNK) {
            int rows = h - y < SHOT_ROWS_PER_CHUNK ? h - y : SHOT_ROWS_PER_CHUNK;
            for (int r = 0; r < rows; r++) {
                bmp_row_from_rgb565(snap->data + (size_t)(y + r) * w * 2, w, LV_COLOR_16_SWAP, out + r * row_bytes);
            }
            err = httpd_resp_send_chunk(req, (const char *)out, (ssize_t)(row_bytes * rows));
        }
        if (err == ESP_OK) {
            err = httpd_resp_send_chunk(req, NULL, 0);
        }
        free(out);
    }
    if (bsp_display_lock(2000)) { /* lv_snapshot_free touches the LVGL image cache */
        lv_snapshot_free(snap);
        bsp_display_unlock();
    }
    if (err == ESP_ERR_NO_MEM) {
        send_status(req, "503 Service Unavailable", "no memory\n");
    }
    return ESP_OK;
}
```
